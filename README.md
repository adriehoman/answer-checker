# Answer Checker

A learning tool for Individual Support students.

Students choose their unit, assessment and question, type their own answer, and get feedback:

- 🟢 Green: your answer seems to cover what the question asks.
- 🟠 Orange: your answer covers part of the question.
- 🔴 Red: your answer does not answer the question yet.

This tool does not give answers. It does not mark your assessment. Your teacher makes the final decision.

You need an access code from your teacher to use it.

**Privacy:** Do not type your name, student number, email, or any personal or health information.

This repository holds only the web page. The answer checking runs on a separate private server.
